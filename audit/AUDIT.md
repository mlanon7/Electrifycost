# ElectrifyCost — Deep Audit Report

**Audit date:** 2026-05-08
**Auditor scope:** entire Astro project at the repo root, including `src/pages`, `src/components`, `src/lib`, `src/data`, `src/styles`, `public`, `scripts`, and config (`astro.config.mjs`, `tailwind.config.mjs`, `vercel.json`, `package.json`).
**Method:** read every file end-to-end; ran `node scripts/smoke-test.cjs` (passes); attempted `npm run build` (blocked by a Linux/Windows rollup-binary mismatch in the mounted `node_modules`, not a code issue); cross-checked claims in FAQ copy against current IRS / DOE / ENERGY STAR / EIA pages via web search.

---

## Executive summary — read this first

The project has a strong foundation: a clean Astro + React-island architecture, a deliberately source-traceable calculator engine in `src/lib/calc.ts`, real CSV-driven data for 50 states + DC, sensible SEO scaffolding, and a print-friendly result UI. The smoke test exercising the calculator math runs cleanly across 13 scenarios. The information architecture (calculator-per-module + state-permutation + methodology + sources + glossary + rebates) is the right shape for a cost-calculator site.

**However, the repo is not currently shippable.** A large fraction of the source files are physically truncated — the file content stops mid-line. Every calculator page except the dynamic state page is incomplete; `src/lib/calc.ts` has no `return` statement in `runCalculator`; `src/lib/data.ts` is missing the `ALL_STATES` export that several files import; `src/components/Layout.astro`, `Header.astro`, `Footer.astro`, `ResultPanel.tsx`, and `src/styles/global.css` all end mid-statement. **The site cannot build until those files are restored.** Details and a precise file list are in §6 (Bugs).

The smoke test (`scripts/smoke-test.cjs`) is a re-implementation of the engine in plain Node and is *not* truncated — that's why it passes. The truncation is in the actual ship-path code, not in the test harness.

**Top priorities, in order:**

1. Restore the truncated source files. Until this is done, nothing else matters because the site won't render.
2. Update the IRA-credit dates and FAQ copy. The One Big Beautiful Bill Act (OBBBA, signed 2025-07-04) sunset 25C on 2025-12-31 and 30C on 2026-06-30 — the `expiration_date` columns in `rebate-programs.csv` happen to be correct, but the FAQ language ("through December 31, 2025") needs to shift to past tense for any 2026 reader and the federal-credit infrastructure needs to gracefully degrade.
3. Add a real OG image and ship the missing structured-data and `lastmod` hints.
4. Wire `src/lib/analytics.ts` into the calculator components — the `track()` function exists but is never imported anywhere.
5. Build out the medium-effort, high-leverage pages identified in §2 (programmatic state pages for the four other modules; comparison pages; spending guides).

## 1. What's there now

### Tech stack and runtime

- **Framework:** Astro 4.15 with React Island hydration. SSG with `astro build`.
- **UI:** React 18.3 in five calculator islands; `client:load` in the page templates.
- **Styling:** Tailwind 3.4 with a custom green/blue palette (`tailwind.config.mjs`) plus a small set of component classes in `src/styles/global.css` (`.card`, `.btn-primary`, `.input`, `.calc-grid`, `.ad-slot`, etc.).
- **Data:** six CSVs + two JSONs in `src/data`. Loaded at module initialization in `src/lib/data.ts` via Vite's `?raw` query and parsed with a small in-house CSV reader.
- **Sitemap:** generated by `@astrojs/sitemap`; emitted as `/sitemap-index.xml`. Referenced from `public/robots.txt`.
- **Hosting:** `vercel.json` configures clean URLs, trailing slashes, immutable cache for assets, sensible security headers (`X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy: camera=(), microphone=(), geolocation=()`, `X-Frame-Options: SAMEORIGIN`).
- **Test:** `scripts/smoke-test.cjs` re-implements the calculator engine in plain Node and walks 13 scenarios from `scripts/smoke-cases.json`. `npm test` runs it; output is human-readable `* label / gross / net / panel risk / monthly impact / incentives`.
- **Analytics:** stub at `src/lib/analytics.ts` with an `AnalyticsEvent` union type and a `track()` function that no-ops in production and `console.debug`s on localhost. **Not imported anywhere yet.** (See §6.)

### Components

All five calculator components (`HeatPumpCalculator.tsx`, `EvChargerCalculator.tsx`, `PanelCalculator.tsx`, `HpwhCalculator.tsx`, `InductionCalculator.tsx`) are complete, end-to-end. They share a shape: form on the left, `<ResultPanel result={result} />` on the right, `useMemo` of `runCalculator(args)` over input state. `Layout.astro`, `Header.astro`, `Footer.astro`, and `ResultPanel.tsx` are **truncated**.

### Calculator engine

`src/lib/calc.ts` defines `runCalculator(args: CalcArgs): CalculatorResult`. The model:

```
gross = (material + labor*rate*state_mult + permit) × difficulty × homeType × timing
       + circuit_adder + removal_adder + panel_adder
net   = gross − sum(eligible_incentives)
```

Plus operating-cost change via a HDD × UA model for heat pumps, NEEA-anchored figures for HPWH, ENERGY STAR/RMI deltas for induction, and an AFDC-anchored model for EV. Simple payback = net / annual savings. Panel risk weighting is probabilistic (medium = 40%, high = 75%, critical = 100%). The function body in the shipping file is **truncated mid-`caveats` array** — see §6.

## 3. FAQ sources — quality review

### What's there

- Two pages emit `FAQPage` JSON-LD: `electrical-panel-upgrade-cost-calculator.astro` (9 Q&A) and `heat-pump-cost-[state].astro` (4 Q&A). Both are correctly shaped: `@type: Question`, `acceptedAnswer.@type: Answer`, `text` value.
- The other calculator pages have `faq` arrays in the frontmatter but the page body — including the `FAQPage` schema — is missing because the file is truncated. So the FAQ content exists but is neither rendered to readers nor exposed to crawlers.
- No FAQ entry in any page links to a primary source. The IRS, DOE, ENERGY STAR, NEEP, and ACCA pages exist in `source-notes.json` but nothing in the FAQs cites them.

### Specific FAQ-content findings

#### Heat pump (`heat-pump-cost-calculator.astro`, FAQ 4 + 5)

> "Through December 31, 2025, the federal Energy Efficient Home Improvement Credit (25C) provides 30% of cost up to $2,000 for qualifying ENERGY STAR heat pumps."

**Severity: high.** OBBBA (signed 2025-07-04) terminated 25C for property placed in service after 2025-12-31. As of audit date this language is technically still defensible for tax-year-2025 filings, but a 2026 visitor reading the page will assume the credit is currently available and may be misled. **Recommendation:** rewrite to past tense and state that the credit was repealed by OBBBA, citing [IRS — Energy Efficient Home Improvement Credit](https://www.irs.gov/credits-deductions/energy-efficient-home-improvement-credit) and [ENERGY STAR Federal Tax Credits](https://www.energystar.gov/about/federal-tax-credits). Same fix needed for FAQ 5 ("DOE Home Energy Rebates (HEEHRA) add another $4,000–$8,000…") — the program is funded but state rollout is now uneven and several states (e.g., CA HEEHRA single-family) have been fully reserved. Cite [DOE Home Energy Rebates — current state status](https://www.energy.gov/scep/home-energy-rebates-programs).

#### Heat pump (FAQ 7)

> "Typical service life is 15 years for ducted heat pumps and 20 years for mini-splits…"

**Severity: low.** No source cited. Replace with a citation to [DOE Energy Saver — Heat Pump Systems](https://www.energy.gov/energysaver/heat-pump-systems) (which gives 15 years typical) or to the [NREL End-Use Load Profile / Building America technical reports](https://www.nrel.gov/docs/fy23osti/85075.pdf). The "20 years for mini-splits" claim is industry lore, not DOE data — soften to "manufacturers commonly cite 15–20 years; field data is sparse."

#### Heat pump (FAQ 9 — Manual J)

> "Manual J is the ACCA standard residential load calculation."

**Severity: low.** Correct. Cite [ACCA Manual J — 8th Edition](https://www.acca.org/standards/manual-j) so readers can see the actual standard.

#### Heat pump (FAQ 10 — HSPF2)

> "HSPF2 (Heating Seasonal Performance Factor, 2023+ standard) measures heating efficiency. Higher is better. ENERGY STAR–certified heat pumps must hit HSPF2 ≥ 7.5; cold-climate models often reach 8.1+. The legacy HSPF rating is roughly 15% higher for the same equipment, so don't compare across the two."

**Severity: medium.** The HSPF2 → HSPF conversion factor is closer to ~85% (i.e. HSPF2 = 0.85 × HSPF), not "15% higher." Also the ENERGY STAR thresholds vary by region and form factor (split / packaged / mini-split / cold-climate). Replace "must hit HSPF2 ≥ 7.5" with the form-factor-specific values from [ENERGY STAR Air-Source Heat Pump Specifications](https://www.energystar.gov/products/heating_cooling/heat_pumps_air_source/key_product_criteria) and [NEEP cold-climate ASHP database](https://ashp.neep.org/).

#### EV charger (`ev-charger-installation-cost-calculator.astro`, FAQ 4 + 5)

> "Yes — the federal 30C credit covers 30% of cost up to $1,000 for qualifying property placed in service through June 30, 2026."

**Severity: medium.** Date is correct (OBBBA changed the prior 2032 date to 2026-06-30). Cite [IRS — Alternative Fuel Vehicle Refueling Property Credit](https://www.irs.gov/credits-deductions/alternative-fuel-vehicle-refueling-property-credit) and [Form 8911 instructions (12/2025)](https://www.irs.gov/instructions/i8911) and [AFDC eligible-census-tract lookup tool](https://afdc.energy.gov/laws/30C). FAQ 5 references "the DOE's Alternative Fuels Data Center" — link directly to the [eligible census tract mapping tool](https://www.energy.gov/articles/30c-alternative-fuel-vehicle-refueling-property-tax-credit).

#### EV charger (FAQ 2 — hardwired vs plug-in)

> "Hardwired chargers can support continuous 48A charging and are required by code for some models above 40A continuous."

**Severity: low.** Correct, but the underlying NEC rule is the 80% continuous-load derating in NEC 625.41 / 210.20(B). Cite [NEC 625 Article — EV Power Transfer System](https://www.nfpa.org/codes-and-standards/all-codes-and-standards/list-of-codes-and-standards/detail?code=70) and the [SAE J1772 reference](https://www.sae.org/standards/content/j1772_201710/). Tesla / non-Tesla NACS adapter context may be worth a sentence post-2024.

#### Panel upgrade (`electrical-panel-upgrade-cost-calculator.astro`, FAQ 4 — load management)

> "NEC 750-listed energy management systems schedule large loads…"

**Severity: low.** Article number is correct. Cite [NEC Article 750 — Energy Management Systems](https://www.nfpa.org/) (or any of the NEMA explainers) and add a primary link to a manufacturer specsheet from Span / Lumin / DCC for credibility.

#### Panel upgrade (FAQ 6 — 25C eligibility for panels)

> "Through December 31, 2025, the federal Energy Efficient Home Improvement Credit (25C) covers panel upgrades up to $600 (30% of cost), but only when installed in connection with a qualified energy efficiency improvement…"

**Severity: high.** Same OBBBA issue as Heat pump FAQ 4. Update language and cite [IRS 25C](https://www.irs.gov/credits-deductions/energy-efficient-home-improvement-credit). The "$600 cap for panels" detail is correct under 25C(c)(2)(B) and survives in the IRS FAQ.

#### HPWH (`heat-pump-water-heater-cost-calculator.astro`, FAQ 4)

> "DOE Home Energy Rebates provide additional amounts for income-qualified households."

**Severity: medium.** Add cap context — the HEEHRA cap for HPWH is $1,750. Cite [DOE Home Energy Rebates programs](https://www.energy.gov/scep/home-energy-rebates-programs) and link to your state administrator (e.g., CA TECH HEEHRA, NYSERDA, Mass Save).

#### HPWH (FAQ 3 — room size)

> "Roughly 700 cubic feet of free air for a typical hybrid model."

**Severity: low.** This is the manufacturer rule of thumb but varies by model from 450–1,000 ft³. Cite [DOE Energy Saver — Heat Pump Water Heaters](https://www.energy.gov/energysaver/heat-pump-water-heaters) and one manufacturer install manual (Rheem / AOSmith / Bradford White / SanCO₂).

#### Induction (`induction-stove-cost-calculator.astro`, FAQ 4 — 25C / HEEHRA)

> "No. The Energy Efficient Home Improvement Credit (25C) does not cover stoves directly. Income-qualified households may qualify for the DOE Home Energy Rebate of up to $840 for an electric stove/cooktop/range — administered by states."

**Severity: low.** Correct. Cite [DOE HEEHRA program page](https://www.energy.gov/scep/home-energy-rebates-programs) and link to a state administrator example so readers can see the actual application flow.

#### State page templates (`heat-pump-cost-[state].astro`, all 4 FAQs)

The state-FAQ language is generated. The dollar amounts and rebate counts are correct because they come from the data files. **Two improvements:**

1. The "Is a heat pump worth it" answer for cold states cites HDD and oil price — add a citation to [EIA State Energy Profiles](https://www.eia.gov/state/) with a per-state deep link, since `state` is in scope.
2. The "What rebates" answer says "DOE Home Energy Rebates as they roll out". Some states have now opened HEEHRA (CA single-family is fully reserved as of Feb 2026; NY, MA, ME, GA, AZ, etc., are running). Add per-state status from your CSV (a new column would help) and cite the [state-by-state status tracker](https://www.energy.gov/scep/home-energy-rebates-programs).
